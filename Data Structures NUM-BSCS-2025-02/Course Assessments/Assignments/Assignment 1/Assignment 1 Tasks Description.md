# **Task 1: LRU Cache for an AI/Web Application using Doubly Linked List**

## Requirements & Functionality
1. Implement `put(key, value)`
2. Implement `get(key)`
3. Move an accessed item to the front
4. Remove the least recently used (LRU) item when capacity is reached
5. Display the cache contents
6. Display current cache size

5. Delete a block
