# **Task 1: Equation Balancer Checker using Stack**

## Requirements & Functionality
1. Take an expression containing parentheses, braces, and brackets (e.g., `{[()]}`) as input
2. Utilize a stack to check if the brackets/parentheses are properly matched and balanced
3. Output "Balanced" if valid; otherwise, output "Not Balanced"

# **Task 2: Stack-Based Tower of Hanoi Game**

## Requirements & Functionality
1. Represent the three rods (A, B, and C) using stack data structures
2. Initialize rod A with $n$ disks stacked in decreasing size from top to bottom
3. Interactive move execution: Allow the user to specify source and destination rods
4. Validate move legality (ensure a larger disk is never placed on top of a smaller disk)
5. Track and display total user moves alongside the minimum required moves ($2^n - 1$)
6. Detect winning condition when all disks are successfully transferred from rod A to rod C
