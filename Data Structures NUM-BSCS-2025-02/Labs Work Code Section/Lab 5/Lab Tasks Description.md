# **Task 1: AI Agent Task Manager using Singly Linked List**

## Requirements & Functionality
1. Add a new task at the beginning
2. Add a task at the end
3. Insert a task after a given Task ID
4. Delete a task using Task ID
5. Search for a task
6. Display all pending tasks
7. Count the total number of tasks
8. Mark a task as completed
9. Display completed and pending tasks separately

# **Task 2: Web Browser Navigation using Doubly Linked List**

## Requirements & Functionality
1. Visit a new webpage
2. Go back
3. Go forward
4. Display complete browsing history
5. Delete a particular webpage using URL
6. Search whether a URL exists in history
7. Display history from newest to oldest
8. Clear browser history
