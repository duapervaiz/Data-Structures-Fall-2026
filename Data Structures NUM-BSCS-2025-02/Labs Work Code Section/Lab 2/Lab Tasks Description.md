# **Static Array and Dynamic Array**

# Task 1: Diagonal Matrix Checker
Write a C++ program to read elements in a matrix and check whether the matrix is a Diagonal matrix or not (all elements above and below the principal diagonal are zeros).

# Task 2: Dynamic Array Operations with Menu
Design and implement a dynamic array in C++ with separate functions for:
- Insert
- Update
- Delete
- Search
Includes a user-friendly console menu interface.

# Task 3: 2D Boolean Friendship Matrix & Common Friend Checker
Create a 5x5 boolean 2D array representing friendships between people (0 to 4). Implement a method to check whether two specified people share a common friend.

# Task 4: Student Semester GPA Calculator using Jagged Array
Write a program to calculate the GPA of students across different numbers of enrolled subjects in a single semester using dynamic/jagged array memory allocation.
