# **Task 1: Simple Queue Implementation using Array**

## Requirements & Functionality
1. Enqueue: Add an element to the rear of the queue
2. Dequeue: Remove an element from the front of the queue
3. Peek: Display the front element without removing it
4. Handle Underflow and Overflow states (empty or full queue)


# **Task 2: Circular Queue Implementation using Array**

## Requirements & Functionality
1. Handle wrap-around when the rear reaches the end of the array
2. Enqueue: Add an element to the rear of the circular queue
3. Dequeue: Remove an element from the front of the circular queue
4. Peek: Display the front element without removing it
5. Properly detect and handle full and empty queue states


# **Task 3: Priority Queue Implementation**

## Requirements & Functionality
1. Enqueue elements associated with priority values
2. Dequeue elements in order of priority (higher priority elements dequeued first)
3. Display all queue contents alongside their respective priorities
