# DATA STRUCTURES
## Fall 2026

Welcome to the official repository for the **Data Structures (CSC-200)** course (Fall 2026). This repository serves as a centralized collection of C++ implementations, lab experiments, algorithm demonstrations, and course assignments.

---

### 📂 Repository Structure

* **[Labs Work Code Section](./Labs%20Work%20Code%20Section/)**
  Contains code implementations, exercises, and problem sets completed across weekly laboratory sessions:
  * **Lab 1:** Basic C++ File I/O (`genome.txt`) & OOP Concepts (Shallow vs. Deep Copy, Rule of Three)
  * **Lab 2:** Static & Dynamic Arrays (Diagonal Matrix, Dynamic Array Class, 2D Friendship Matrix, Jagged Array GPA Calculator)
  * **Lab 3:** Singly Linked List Operations (Insertion, Deletion, Search, Traversal, Update)
  * **Lab 4:** Circular & Doubly Circular Linked List Applications
  * **Lab 5:** Linked List Challenge Projects (AI Agent Task Manager, Web Browser Navigation, Smart Learning Playlist, AI Model Request Scheduler)
  * **Lab 6:** Expression Conversion using Stacks (Infix, Postfix, Prefix)
  * **Lab 7:** Queue Data Structures (Simple Array Queue, Circular Queue, Priority Queue)

* **[Course Assessments/Assignments](./Course%20Assessments/Assignments/)**
  Contains comprehensive course assignments focused on real-world data structure applications:
  * **Assignment 1:** Linked List Applications
    * *Task 1:* Least Recently Used (LRU) Cache using Doubly Linked List
    * *Task 2:* Simplified Educational Blockchain Transaction Chain using Singly Linked List
    * *Task 3:* Multimedia Playlist Manager using Doubly/Circular Linked List
    * *Task 4:* Integrated Challenge (Custom Linked List Application)
  * **Assignment 2:** Stack Applications
    * *Task 1:* Expression Parentheses & Bracket Balancer Checker
    * *Task 2:* Interactive Stack-Based Tower of Hanoi Game
